# 湉码 / tiancode v1.0 功能达标与验收矩阵 (唯一验收合同)

本文档为湉码 / tiancode 正式冻结的唯一验收合同与真实交付基准。  
彻底作废早期草案中的虚构假交付项（如虚构的 Python/Air-Gap/Test Explorer/settingsStore 等），所有评价以当前真实运行路径（Wails v2 + Go 微内核 + Vue 3）与可验证事实为准。

---

## 🎯 唯一主旅程达标线

```mermaid
flowchart LR
    A["1. 打开真实项目"] --> B["2. 配置真渠道探活"]
    B --> C["3. 选择执行策略"]
    C --> D["4. 发起目标任务"]
    D --> E["5. 先检索/地图后改代码"]
    E --> F["6. Diff 审查与采纳"]
    F --> G["7. TDD 双栈测试验证"]
    G --> H["8. Git 本地提交"]
```

**主旅程达标验收标准**：
1. **Agent 不盲扫**：工作区提供一等检索工具 `search_workspace` (grep/find) 与顶层清单缓存；审查模式强制拦截写操作与深层非清单探索。
2. **任务看得见**：顶栏状态徽章（执行中 / 待确认 Diff / 已达上限 / 测试未通过 / 已完成 / 已中断）与阶段统计强同步；存在待确认改动时阻断新轮次并弹窗二次确认。
3. **编辑器够用**：文件树支持深层展开与文件名实时过滤；Monaco 编辑器支持多文件页签、未保存脏标记与磁盘读写。
4. **Diff 是主路径**：Agent 改写文件自动调出 Diff 视图并高亮变更；支持 Hunk 级与整文件级采纳/放弃。
5. **TDD 认真实栈**：支持 Go (`go test`) 与 Node (`npm test`) 真实双栈探测与执行；测试失败时顶栏红灯阻断，严禁模型虚假宣称完成。
6. **失败可续**：触顶、网络异常、中止均输出人话说明；输入「继续」自动接续前序目标。
7. **设置只承诺现货**：仅保留真实可落盘生效的能力（stdio MCP、渠道测速、本地规则/技能注入），剔除虚构入口。

## 📊 现货事实与功能达标矩阵

> **评分说明**：
> - 🟢 **达标**：主路径可独立完成、失败有交代、不靠用户猜、全链路测试验证通过。
> - 🟡 **半成品**：具备真实核心链路，仍需补齐部分工程体验或覆盖面。
> - 🔴 **不达标 / 实验性**：深度不足或非现货能力，严禁在 v1.0 中标为完成。

| 模块 | 现货事实 (Real Implementation) | 现状评分 | 达标差距与收敛现状 (Gap to Bar & Status) |
| :--- | :--- | :---: | :--- |
| **对话 / Agent 引擎** | 流式推理、24轮循环、TaskModel 目标接续、人话收尾、驾驶舱状态徽章；新增 `search_workspace` (grep/find) 算子。 | 🟢 达标 | 已提供一等检索工具，System Prompt 强制「先检索与先地图再下钻」；触顶与错误全面人话化。 |
| **执行策略与防线** | 支持 `analyze` (只读审查)、`implement` (直接改代码)、`tdd` (测试闭环)；发送栏实时显示策略拦截规则，输入审查意图自动切换 analyze。 | 🟢 达标 | 首轮硬闸严格白名单根目录清单；发送栏直观展示策略边界；模型无法突破只读写盘限制。 |

## 🚫 明确排除在 v1.0 验收范围外的演进特性

1. **Swarm 复杂多智能体编排**：v1.0 专注于单 Agent 高质量 Coding 闭环，不引入未稳定的实验性 Swarm 概念；
2. **多终端 PTY 虚拟终端**：当前保持静默无弹窗流式执行已足够满足工程闭环；
3. **LSP 完整语言服务器协议集群**：v1.0 依托编译器诊断与 Monaco 本地高亮，全套 LSP 纳入 v1.2 规划；
4. **Air-Gap 物理离线隔离**：已作废，不做虚假宣传。
